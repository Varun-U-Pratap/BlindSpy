### E01 — Majority-class baseline, all tasks and timeouts (2026-10-28, utsav-s-r)

Hypothesis: a model that always predicts the largest training class sets the floor every
model must beat. Its validation accuracy equals that class's share p of the validation set,
and its macro F1 equals 2p / ((1 + p) k) for k classes (F1 of the predicted class is
2p / (1 + p); every other class scores 0). The stratified split keeps p the same in train and
validation, so CV and validation should agree.

Threshold (set before running, never moved afterwards): supported if, in all 16 configs
(4 tasks x 4 timeouts), |validation accuracy - p| <= 0.001 and
|validation macro F1 - 2p / ((1 + p) k)| <= 0.001. Any miss means a bug in the pipeline or
the metrics, and the runs are not used until it is fixed.

Change: none (first baseline). Model `majority` = `DummyClassifier(strategy="most_frequent",
random_state=42)`. Configs: `configs/experiments/E01_majority_<task>_<timeout>s.yaml`
(generated by `scripts/make_configs.py`). Protocol: 5-fold stratified CV on train, fit on
train, score on validation (test not used). Data version v1.

Result: 80 baseline runs, all FINISHED, from dev commit 1817c5a (committed and pushed;
tag v0.1-baseline). Numbers below come from `reports/baseline_tables.md` (generated by
`scripts/results_tables.py` from `reports/history.csv`).

- All 16 configs match the arithmetic to 4 decimals (table "E01 check"): e.g. A1 15 s, largest
  class VPN, p = 0.5185, validation accuracy 0.5185, expected and measured macro F1 0.3414; B 15 s,
  largest class VOIP, p = 0.1560, macro F1 0.0193.
- The floor in validation macro F1: A1 0.337-0.358, A2-VPN 0.060-0.093, A2-NonVPN 0.067-0.096,
  B 0.019-0.030. Balanced accuracy is exactly 1/k (0.500, 0.143, 0.071) and A1 ROC-AUC 0.5.
- The largest class changes with the timeout (A1: VPN at 15/30 s, Non-VPN at 60/120 s;
  A2-NonVPN: VOIP at 15 s, BROWSING after; B: VOIP at 15 s, BROWSING after), as E00 found.
- CV on train equals validation (std 0.000): the stratified split keeps class shares equal.
- Cost: under 0.03 s to train, about 1.4 KB per model file.

Verdict: supported (16 of 16 configs within 0.001 on both checks).

Decision: keep as the floor. Every later model is compared with it. Next: E02, E03.
